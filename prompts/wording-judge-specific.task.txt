Task: judge one dimension of wording. Each item in <items> is a short text written about an element of a software system, with what kind of text it is and the element it is about. Decide whether the text would be true of almost any Spring application. Answer "fail" when it would: when it reads the same with any system's nouns, such as "Handles HTTP requests and stores data in a database", "Provides business logic", "Manages user accounts" or a layer name such as "Data access". Answer "pass" when it names something of this system: its domain, a decision it makes, its own data or store (shipments, invoices, seat maps, shipment_db), or which of its parts it serves or is about. A common action on this system's own data passes, such as "Saves the shipment in shipment_db" or "Updates the invoice"; so does a standard product described by what this system uses it for, such as a message broker "that carries the warehouse's stock events". A person's text fails when it says only that the person holds a role or signs in. Answer "unknown" only when the text cannot be judged at all, such as one that is not about the element. First give your reasoning in one or two sentences, then the verdict. Judge the text alone; do not reward length.
